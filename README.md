# Сортировщик продукции на конвейере

Курсовой VHDL-проект для **QMTECH Cyclone 10 Starter Kit V03**, ПЛИС `10CL080YU484C8G`, такт 50 МГц. [Отчёт](docs/report/report.pdf) содержит диаграмму автомата, временные диаграммы и листинги.

## Устройство

- `conveyor_sorter.vhd` проверяет диапазон веса **95–105 включительно**. При первом спаде после центра он фиксирует предыдущий отсчёт. При освобождении датчиков после центра фиксирует последний отсчёт, а проход без центра пропускает. Разрешение конвейера постоянно. Импульс отбраковки длится `REJECT_PULSE_CYCLES` тактов.
- `flow_tester.vhd` выдаёт табличные профили с зафиксированными весами 100 и 80. Датчики и вес обновляются вместе раз в `STEP_CYCLES` тактов. После сброса первым идёт годное изделие.
- `qmtech_demo_top.vhd` соединяет генератор и ядро, синхронизирует снятие кнопочного сброса и инвертирует выходы для светодиодов. При 50 МГц ожидаются постоянно включённый D1 и импульсы D2 по 100 мс раз в 3,2 с.
- `conveyor_sorter_top.vhd` содержит отдельную обёртку для внешних датчиков. Для согласованной передачи веса внешний источник должен удерживать стабильный код с учётом задержки фильтра. Назначения контактов демонстрации относятся к `qmtech_demo_top`.

У ядра отдельные тактовые процессы для переходов по `case` и обновления регистров. Для сравнения веса используется `IEEE.STD_LOGIC_UNSIGNED`. Счётчики идут вниз до нуля, выходы генератора зарегистрированы.

## Проверка

Из корня репозитория выполните `./scripts/test.sh`. Скрипт использует VHDL-2008 и `-fsynopsys`. Путь к GHDL можно задать переменной `GHDL`.

Семь запусков проверяют границы веса, длительности импульса 1/2/3/8 тактов, однотактное срабатывание обоих датчиков, восстановление после прохода без центра и сброс во время импульса. При шаге генератора 1/2/8 тактов тестбенч сверяет каждый отсчёт датчиков, веса и отбраковки. Отдельная проверка подтверждает отказ при неверных границах веса. Для Questa предусмотрен сценарий `do /полный/путь/task1/test_alternating.do`.

[Протоколы проверок](docs/verification/README.md), [разбор архитектурных решений](docs/REVIEW_NOTES.md) и [сборка PDF](docs/report/README.md).

## Сборка для платы

Откройте `task1/qmtech_demo.qpf` в Quartus и выполните полную компиляцию. В командной строке из `task1`:

```sh
quartus_sh --flow compile qmtech_demo
```

В QSF заданы G1 для такта, P4 для SW1, V10 для D1 и U9 для D2. Сверьте маркировку платы с V03. [Схема QMTECH V03](https://github.com/ChinaQMTECH/CYCLONE_10_STARTER_KIT/blob/master/V3_10CL080YU484/Hardware/QMTECH-Cyclone10-Starter-Kit-V03.pdf)

Текущая редакция прошла моделирование и синтез RTL в GHDL. Полную компиляцию Quartus, проверку TimeQuest на 50 МГц и испытание платы для этой редакции предстоит выполнить. В Programmer выберите USB-Blaster, выполните Auto Detect и загрузите SOF новой сборки через Program/Configure.
