# Аппаратная проверка и сдача

1. Собрать `task1/qmtech_demo.qpf` в Quartus. Сохранить итог компиляции, файл SOF и отчёт TimeQuest по ограничению 20 нс.
2. Сверить маркировку платы с QMTECH V03 и 10CL080YU484C8G. Загрузить SOF актуальной сборки через USB-Blaster.
3. Проверить постоянно включённый D1, импульсы D2 по 100 мс с периодом 3,2 с и повторный запуск после SW1.
4. Дополнить раздел об аппаратной проверке результатами, пересобрать PDF и заполнить дату и подписи.
