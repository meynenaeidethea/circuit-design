# Отчёт по проекту «Сортировщик продукции на конвейере»

Итоговый файл: `report.pdf`. Исходники Typst: `report.typ` и `title.typ`. Изображения, схемы и шрифты находятся в `assets/` и `screens/`. В приложении PDF приведены десять исходных файлов и файлов настроек проекта из `project/task1/`.

Отчёт учитывает замечания преподавателя: конечный автомат описан через `case state_r`, сигнал `nextState_s` удалён, ширина шины веса обозначена явно, а тестовые сценарии охватывают пять состояний, границы диапазона 95–105, импульс отбраковки, освобождение датчиков, отсутствие центра и асинхронный сброс.

Снимок Flow Summary и снимки RTL/Technology Map получены до последней правки автомата. Успешная сборка Quartus, показанная на снимках, относится к прежней версии. Актуальные исходники Quartus не пересобраны: Quartus отсутствует в среде. ModelSim собрал VHDL-файлы без ошибок и предупреждений, но запуск симуляции остановился с ошибкой RPC до выполнения тестов. Фактическая загрузка и проверка платы не подтверждены. Эти ограничения отмечены в отчёте и чек-листе.

## Пересборка PDF

Нужен Typst 0.15.1 или совместимый выпуск, Windows и шрифт Courier New. В репозитории запустите сборку из `docs/report`; в ZIP-пакете используйте его корневую папку:

```powershell
typst compile --font-path "assets/fonts;C:\Windows\Fonts" report.typ report.pdf
```

Снимки Quartus и waveform находятся в `screens/`. Подписи, дата, оценка и баллы оставлены незаполненными для сдачи.
